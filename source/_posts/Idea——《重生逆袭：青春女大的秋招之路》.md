### Buff：

|**状态名称**|**触发条件**|**效果 \(Effect\)**|**策划设计意图**|
|---|---|---|---|
|【高压/焦虑状态】<br>\(Debuff\)|焦虑 \(Stress\) ≥ 70|行动消耗增加：除了【打瓦】，所有行为耗费的 AP \+1<br>（例如【自学】由 3 AP 变为 4 AP）。|逼迫玩家不能一味“硬肝”，必须适时选择【打瓦】降焦虑，形成策略阻尼。 |
|【崩盘预警】<br>\(Debuff\)|焦虑 \(Stress\) ≥ 90|AP 上限扣减：下回合初始恢复 AP 降为 7 点（原为 10 点）。|给玩家发出最后通牒！若连续 2 回合达到 100 则直接进入【抑郁休学】败北结局。 |
|【心如止水/自信】<br>\(Buff\)|心态 \(Mindset\) ≥ 80|效率加成：执行【自学】与【肝 Demo】时，获得的能力/履历额外 \+2 |鼓励玩家维持高心态，拉开策略收益差距。|

> 注意：
>
> 当 Stress ≥ 70 时，即便 Mindset \> 80 也不触发正面 Buff；
> 
> 在 `ActionManager` 中计算扣费时，必须采用 `ActualCost = BaseCost + (Stress >= 70 ? 1 : 0)` 计算；
> 
> 允许玩家在 AP 不足扣减时直接点击“进入下一周/结束回合”，避免卡死。
>

**结局判定逻辑：**

```C#
public enum EndingType
{
    None,
    DepressionBurnout, // 焦虑过度抑郁症休学治疗
    GraduationDelay,   // 能力不足延毕
    IndieDev,          // 隐藏：独立游戏制作人
    AAAOffer,          // 完美：大厂核心研发
    Normal             // 兜底：平平无奇
}

public class EndingEvaluator
{
    /// <summary>
    /// 实时检查：是否在回合途中触发【抑郁症休学】
    /// </summary>
    public static bool CheckMidGameFailure(int highStressTurns, out EndingType ending)
    {
        ending = EndingType.None;
        
        // 规则：高焦虑（>=90）持续了 2 个回合
        if (highStressTurns >= 2)
        {
            ending = EndingType.DepressionBurnout;
            return true; // 触发提前结束
        }
        
        return false; //继续游戏至15回合
    }

    /// <summary>
    /// 第 15 回合结束时执行：全条件漏斗匹配（100% 覆盖所有分支）
    /// </summary>
    public static EndingType EvaluateFinalEnding(int skill, int resume, int mindset)
    {
        // 1. 优先匹配【隐藏结局：独立游戏制作人】
        if (skill >= 80 && resume >= 80 && mindset >= 70)
        {
            return EndingType.IndieDev;
        }

        // 2. 其次匹配【完美结局：大厂核心研发】
        if (skill >= 70 && resume >= 70)
        {
            return EndingType.AAAOffer;
        }

        // 3. 再次匹配【能力不足延毕】
        // （哪怕心态再好、履历再高，能力低于40直接触发延毕）
        if (skill < 40)
        {
            return EndingType.GraduationDelay;
        }

        // 4. 兜底结局：平平无奇 (覆盖例如: 能力55, 履历45 等中间态数值)
        return EndingType.Normal;
    }
}
```



## 画面表现方案

纯 2D UI \+ 2D 动态卡片 / 贴图交互（视觉风格类似《中国式家长》《太吾绘卷》《小黑盒》模拟器类）。

**画面维度**：2D 面板风格。主界面为一个宿舍/书桌场景的 2D 精美背景图。

**交互方式**：基于 UGUI/UI Toolkit 的贴图与按钮交互。

例如：点击书桌上的“笔记本”弹出【自学/肝Demo】菜单；点击书桌上的“笔记本电脑”弹出【肝Demo】菜单；点击“游戏手柄”弹出【打瓦】菜单；或者直接使用最直观的卡片式/清单式按钮。



## 技术栈

**游戏引擎**：Unity 2022\.3 LTS

**渲染管线**：URP \(2D Canvas 模式\)

**UI 框架**：UGUI \+ DOTween \(用于属性变动飘字、按钮缩放与弹窗动画\)

**数据存储与配置**：`ScriptableObject` \(配置行为与事件\)

**核心架构**：全局事件总线 \(`EventBus`\) \+ 单例数据管理器 \(`PlayerStatsManager`\) \+ 通用有限状态机 \(`FSM`\)
